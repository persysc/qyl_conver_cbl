# CBL / QYL 棋库转换工具

一个用于象棋桥 CBL 棋库与清弈 QYL 棋库相互转换的桌面工具。支持同时打开多个棋库、预览棋谱列表和批量转换，转换过程在本地完成，无需启动清弈，也不生成或维护棋谱库搜索索引。

## 主要功能

- **CBL → QYL**：读取新版 CBL 及旧版 2.1 格式（含支持的压缩模式），转换为清弈 QYL v1 棋库。
- **QYL → CBL**：将 QYL v1 棋库转换为新版 CBL。
- **FEN 文本 → QYL**：每行一个 FEN 的 `.txt` 题集（如 `双马例胜士象全101题.txt`）可直接转成 QYL 棋库；自动去重、跳过非法局面、无标题时按「第N题」命名，标准开局写为空起始局面。
- **打开文件夹（递归）**：选择文件夹后自动递归扫描所有子文件夹，加入其中的 `.cbl`、`.qyl` 棋库。
- **拖入文件夹**：把文件夹拖进窗口同样会递归扫描；文件和文件夹可以一起拖。
- **自动双向转换**：一键把每个棋库转成另一种格式，CBL 转 QYL、QYL 转 CBL 自动判断；未选中时处理整个列表，选中时只处理选中的棋库。
- **批量转换**：一次选中多个棋库，逐个转换并显示结果。
- **转换统计**：每次转换后汇总成功、失败、跳过数量以及新增文件数和兼容性提示条数。
- **列表预览**：查看棋谱标题、棋手对阵、赛事、日期和结果。
- **内容保留**：转换两种格式能够表达的棋手、队伍、用时、赛事、地点、轮次、台次、结果、日期、作者、着法分支及注释。
- **重名处理**：保存 QYL 时自动分配唯一标题，目录与棋谱正文同步更新。
- **文件保护**：保留源文件，不删除、不覆盖；目标已存在时直接跳过并计入统计；写入临时文件并回读核对，通过后才提交转换结果。

## 使用方法

1. 启动转换工具，点击 **「打开文件」** 选择一个或多个 `.cbl`、`.qyl` 或 FEN 文本 `.txt`；或点击 **「打开文件夹」** 递归导入整个目录树。
2. 也可以直接把文件**或文件夹**拖入窗口，文件夹会自动递归扫描子目录（`.txt` 需含 FEN 行才会被收录）。
3. 单击左侧棋库，右侧会显示该棋库的棋谱列表。
4. 点击 **「自动双向转换」** 一键转换（未选中棋库时处理全部，选中时只处理选中的）：CBL 转 QYL、QYL 转 CBL、FEN 文本转 QYL；也可以用 **「转为 QYL」**、**「转为 CBL」** 手动指定方向。
5. 查看棋谱列表上方的统计与逐条结果，确认成功、失败、跳过数量，以及改名、跳过坏局或字段无法写入的提示。

转换以**整个棋库文件**为单位，右侧棋谱列表用于预览，不用于选择单局导出。选中项已经是目标格式时会跳过。

### 选择与快捷键

| 操作 | 功能 |
|---|---|
| 单击棋库 | 选择并预览该棋库 |
| Ctrl + 单击 | 添加或取消单个选中项 |
| Shift + 单击 | 连续选择一段棋库 |
| Ctrl + A | 选中已打开的全部棋库 |
| Esc /「取消选中」 | 取消选择，保留已打开的棋库 |
| 棋库旁的「×」 | 从列表移除该棋库，不删除磁盘文件 |
|「清空」| 清空已打开的列表，不删除磁盘文件 |

## 输出文件在哪里？

转换结果与源文件保存在**同一目录**，使用相同文件名和目标扩展名：

```text
D:\棋谱\比赛.cbl  →  D:\棋谱\比赛.qyl
D:\棋谱\残局.qyl  →  D:\棋谱\残局.cbl
```

如果目标文件已经存在，工具会提示失败并保留原文件，**不会覆盖，也不会自动换一个输出文件名**。可先将已有目标改名或移到其他位置，再转换。

输出目录需要有写入权限，并支持硬链接（例如本地 NTFS 分区）。不支持硬链接的文件系统或部分网络目录可能无法完成保存；此时工具会返回错误，源文件和已有目标保持不变。

## CBL 转 QYL 的标题规则

CBL 可以存在同名棋谱，QYL 中的标题则用于定位棋谱，必须唯一。本工具与清弈按相同规则处理：

- 按棋库显示顺序分配标题。
- 重名时追加带空格的 ` (2)`、` (3)` 等后缀，并继续检查是否与已分配标题冲突。
- 空标题或全空白标题使用 **「源文件名 第N局」**，N 为原显示序号；跳过坏局后不重新编号。
- 非空原标题中的缩进和空白保留。
- 最终标题同时写入 QYL 目录和棋谱正文，其他棋谱信息保持原样；调整会列入转换提示。

例如，三局同名棋谱会保存为：

```text
2022年全国象棋甲级联赛
2022年全国象棋甲级联赛 (2)
2022年全国象棋甲级联赛 (3)
```

新版 CBL 只读取目录标记为有效的棋谱，按各局实际长度解析，避免将已删除棋谱的残留或填充区数据当成额外棋谱。

**旧工具已经生成在磁盘上的重名 QYL 不会自动修复。** 建议使用当前工具从原 CBL 重新转换，并先保留旧输出作为备份。如果在清弈中替换了已有棋库，还需同步棋谱库索引。

## 兼容性与转换提示

两种格式的字段并不完全相同，转换无法保证所有文件逐字节往返一致：

- **CBL → QYL**：分组、等级分、资源、邮箱及部分文本时间没有对应字段，非空内容会列入提示。
- **QYL → CBL**：用时规则、棋局性质、棋局立场、部分 ECCO 信息及库创建时间戳可能无法写入，会列入提示。
- 工具保留已有可支持的 ECCO 编号，不调用清弈的开局识别驱动自动补全。
- 文字字段超过 CBL 固定容量时拒绝截断并报错；请保留原始棋库。
- 单局数据异常且记录边界明确时，可能跳过该局或仅保留可读取的着法、注释，并明确提示；目录、记录边界或身份信息损坏时可能拒绝整个棋库。
- 工具不会修复原棋谱的非法走子，也不会把“存在兼容性提示”的结果视为完整无损转换。

请阅读转换结果中的提示，尤其关注跳过的棋谱和未写入的字段。CBL 导出按清弈的读取契约实现，尚未在象棋桥应用中逐局验证，也没有覆盖所有历史格式变体。

格式细节与回归用例说明见 [FORMAT_COMPATIBILITY.md](FORMAT_COMPATIBILITY.md)。
